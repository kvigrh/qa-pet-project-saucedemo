# Пет-проект: Тестирование интернет-магазина Saucedemo

## Описание проекта
В рамках данного пет-проекта проведено функциональное и API-тестирование демо-сайта [Saucedemo.com](https://www.saucedemo.com/).

## Что было сделано
- Составлены тест-кейсы для проверки авторизации, корзины и сортировки товаров.
- Проведено тестирование REST API (DummyJSON) через Postman: GET, POST, PUT запросы, проверка статус-кодов (200, 201) и валидация JSON-ответов.
- Результаты задокументированы и оформлены в виде отчёта.

## Содержимое репозитория
- `Проект тест-кейсы.pdf` — тест-кейсы для ручного тестирования.
- `Проект API - тесты.pdf` — отчёт по API-тестированию.

## Используемые инструменты
- Postman
- Google Sheets
- DummyJSON API
