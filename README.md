## 📌 О проекте
Данный пет-проект создан для демонстрации навыков функционального и API-тестирования. В качестве тестового стенда использован демо-сайт [Saucedemo.com](https://www.saucedemo.com/) и открытое API [DummyJSON](https://dummyjson.com/).

**Цель:** Показать системный подход к тестированию, умение работать с документацией, API и оформлять отчеты.

---

## 🛠 Используемые инструменты
- **Postman** — тестирование REST API.
- **Google Sheets** — создание тест-кейсов и чек-листов.
- **Git/GitHub** — хранение портфолио.

---

## 📂 Структура репозитория
- [`Проект тест-кейсы.pdf`] — тест-кейсы для ручного тестирования (позитивные и негативные сценарии).
- [`Проект API - тесты.pdf`] — отчет по API-тестированию с результатами запросов GET, POST, PUT.

---

## 📊 Что было сделано
### 1. Ручное тестирование
- Составлено **6 тест-кейсов** для проверки авторизации, корзины и сортировки.
- Проверены позитивные и негативные сценарии.
- Результаты задокументированы в таблице со статусами Pass/Fail.

### 2. API-тестирование (Postman)
- Проведены запросы: GET, POST, PUT на базе DummyJSON.
- Проверены статус-коды (200, 201) и валидация JSON-ответов.
- Все результаты собраны в отчете.

---

## 📈 Выводы и рекомендации
В ходе тестирования были выявлены следующие моменты:

- Ошибки валидации на стороне клиента отрабатываются корректно.
- API возвращает ожидаемые статусы, структура JSON соответствует документации.
- Рекомендовано добавить тесты на нагрузку и проверку безопасности форм.
